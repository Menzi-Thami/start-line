# Simplify Journey, Account, the plan builder and page chrome

Evidence for branch `simplify/journey-account-builder` (PR into `staging`). Before captures use staging at `42e6b1c` (after #275); after captures use this branch. Both use the real React app through the existing `e2e/fixtures` pages (`journey.html`, `plan-edit.html`) with synthetic API responses, a pinned clock and reduced motion. No real runner, Strava or production data is used.

Full-page captures; the bottom bar is fixed, so on phone captures it appears part-way down the page.
